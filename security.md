# Security Policy

The **@obvia/collections** project takes security vulnerabilities seriously.

If you believe you have discovered a security vulnerability, please report it responsibly by contacting **Selçuk Çukur** at **<hello@selcukcukur.me>**.

Please do not disclose security vulnerabilities publicly until they have been reviewed and addressed.

When reporting a vulnerability, include enough information to reproduce and evaluate the issue where possible, including affected versions, expected impact, and a minimal reproduction.
